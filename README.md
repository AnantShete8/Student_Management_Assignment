# Student Management System

A simple **Student Management System** developed using Python. This project demonstrates data organization using Python collections and basic student record management operations.

## Features

- Add, search, update, and delete student records
- Store student profile data using dictionaries
- Use lists for subjects and marks
- Use tuples for identifiers
- Use sets for unique departments/subjects
- Calculate student and class averages
- Find the highest scorer
- Filter records by department
- Count student records
- Input validation
- Automated unit tests

## Technologies Used

- Python 3.9+
- Python Collections
- `unittest` for automated testing
